# 37ORBIT 主题浏览首页设计

## 目标

把首页从少量精选内容的展示橱窗，扩展为可以在一级页面完成大致浏览的编辑型首页，同时保留 Orbital Editorial 的品牌首屏。

## 信息架构

1. 顶部保留品牌、主导航、站点介绍和 Current Signal 主推荐。
2. 主推荐之后增加 Latest Stories，按更新时间展示最多 6 篇内容。
3. 再按文章第一个非空 `tags` 值生成主题区，每个主题最多展示 6 篇；没有标签的文章归入“未分类”。
4. `category` 仅作为卡片上的形式元数据，不参与一级主题分组。
5. 首页获取完整已发布文章列表；已有的 homepage slots 继续决定主推荐，不破坏后台精选机制。

## 视觉

- 延续当前深黑、暖橙、冷青、细线和轨道地平线语言。
- Latest Stories 使用一张较大的首条内容加紧凑列表，形成国家地理式的快速扫读入口。
- 主题区使用清晰的大标题、文章数量和非等宽卡片网格，避免退化成普通博客卡片墙。
- 有封面时以图片为主；无封面时使用克制的轨道占位，不制造假图片或假文章。
- 移动端单列，正文文字不小于 16px，交互目标不小于 44px，无横向滚动。

## 数据与失败状态

- `getHomepage()`、`getSettings()` 和 `getPosts({ pageSize: 100 })` 并行请求。
- 首页精选请求失败时保留主题浏览；文章列表请求失败时保留原精选首页。
- 空站点继续显示现有作者占位文案，不注入示例文章。

## 验收

- 一级页面可看到 Current Signal、Latest Stories 和全部已有主题。
- 每篇已发布文章至少在 Latest Stories 或主题区可被发现。
- 主题由标签决定，形式分类不作为主题标题。
- 桌面和 390px 移动端无横向溢出。
- 测试、TypeScript 和生产构建通过；推送 `main` 后，`https://37orbit.com/` 显示新版结构与最新提交内容。

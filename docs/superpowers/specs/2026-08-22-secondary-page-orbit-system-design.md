# 37ORBIT 二级与三级页面统一设计

## 目标

让 Projects、Frames、Diary、文章详情和项目详情与主页共享同一套视觉系统，让用户从主页进入深层页面时感觉是在同一个连续的编辑档案中浏览，而不是切换到旧模板。

## 设计方向

采用“Apple 式克制叙事 × 37ORBIT 轨道档案”：保留主页的深色背景、细线、橙色信号色、青色辅助色、等宽元信息和衬线标题；借鉴 Apple 的大首屏标题、明确单一主动作、稳定容器宽度和连续滚动阅读节奏。

## 页面系统

- **共享 Layout**：深色背景、固定/粘性顶部导航、37ORBIT 品牌、Projects / Frames / Diary 三个有效导航入口、统一页脚和背景轨道装饰。
- **集合页**：统一的 `orbit-collection` 容器，顶部使用编号、英文 eyebrow、中文大标题和简介；内容区采用一张主视觉卡 + 次级内容卡或纵向档案列表。
- **文章详情**：顶部显示返回路径与主题标签；标题采用大字号衬线字体；封面作为单一主视觉；正文使用限制宽度的阅读列；底部提供返回集合和下一步浏览入口。
- **项目详情**：复用文章详情的阅读系统，但用 `PROJECT` 元信息和 Projects 返回路径表达项目类型。
- **Frames**：继续使用影像网格，但卡片、主题分组和标题都切换到统一轨道样式。
- **Diary**：保留文字档案的轻量感，改为带编号、日期、主题和箭头反馈的列表，不再使用旧的圆角白色面板。

## 交互与响应式

- 所有页面只保留一个明显的首要动作：进入内容或返回上一级。
- 卡片 hover 只使用边框、位移和图片轻微缩放，持续时间 180–320ms。
- 移动端单列布局，正文不小于 16px，导航和返回按钮触控高度不小于 44px。
- 所有页面禁止横向滚动；图片使用懒加载并保留比例空间。
- 保留键盘 focus-visible 轮廓和图片预览关闭按钮的可访问标签。

## 数据与错误状态

继续复用现有 `contentService`，不改变 CMS 数据结构。集合页使用已有分类查询，详情页使用已有 slug 查询；加载、空状态和错误状态都使用统一的轨道文案和表面样式。

## 验收标准

1. Projects、Frames、Diary 与主页共享顶部导航、背景、字体、色彩和页面容器。
2. 文章详情和项目详情与主页共享标题、元信息、按钮、边框和阅读宽度。
3. 页面在 1280px 桌面和 390px 手机宽度下均无横向溢出。
4. 所有有效导航和文章链接可到达，加载/空/错误状态不出现旧版白色卡片风格。
5. 构建、类型检查和已有单元测试通过，并在生产站点实际验收。
